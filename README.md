# LireMonde

LireMonde est une application web de gestion de bibliothèque permettant d'explorer, rechercher et gérer une collection de livres.

## Fonctionnalités

- **Catalogue de livres** : Explorez une collection variée avec filtres par genre (Classique, Science-fiction, Drame, Fantasy)
- **Recherche avancée** : Recherchez des livres par titre ou auteur
- **Liste "À lire"** : Ajoutez des livres à votre liste de lecture personnelle
- **Administration** : Gérez les livres (ajout, modification, suppression) via un tableau de bord

## Technologies

- HTML5, CSS3, JavaScript (Vanilla)
- [JSON Server](https://github.com/typicode/json-server) - API REST simulée
- Google Fonts (Playfair Display, DM Sans)
